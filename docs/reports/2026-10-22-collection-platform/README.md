## 交付结构与数据契约

代码入口为 `scripts/run_collection.py`，只支持两个仿真后端，不提供 real backend 选项。共享模块为 `episode_schema.py`、`collection.py`、`collection_sources.py`、`arm_mapping.py`、`collection_stream.py`；子代理分别只修改自己的 `collection_sapien.py`、`collection_mujoco.py` 和专属报告。原方向键任务实现与数值没有改变。使用和以后部署的说明见[collection.md](../../usage/collection.md)。

episode v2 使用 JSON journal，左右顺序 left/right，五指 thumb/index/middle/ring/pinky。双手包含原始电机指令、映射关节指令及实际 21 关节；双臂包含原始主臂 deg、最终从臂 rad 及实际 7 关节；世界位姿统一 `[x,y,z,qw,qx,qy,qz]`、平移 m、world-from-frame，四元数归一化且 w 非负。实际引擎时间、Unix 墙钟 ns、掌根、五指指尖、32 维信号/mask、全部控件位移、overlay 和备注同帧保存。

meta 包含场景规范全文及 SHA256、场景变体定义、引擎/资产/映射版本、startup reference 与限幅、占位驱动参数、输入来源、右安装 assumed 和指尖偏移。无法取得的原始主臂指令记 null，不能从最终 rad 逆推。手关节实测是仿真状态，不是声称真实硬件有 21 路独立传感器。

指尖采用 distal frame 朝向和碰撞网格局部 `[0,0,max_z]`，复用可行性分析的几何参考定义，不是实测指腹点。两后端共同调用 helper。L1/L2 变体通过 `--scene-variant free-space` 选择；默认 full 保持原场景碰撞。变体定义进入场景哈希，没有偷偷改配置。

右手保留与 L25/right 一致的资产及右侧 mimic 系数；安装按用户批准的对称假设标记 assumed。沿用 v4.4 的手柄固定装置，没有采用双手可行性报告的架高/倾斜建议；遥操参考轨迹不等于已取得全控件握持证书。

## 原始事实与来源复核

- 手命令 `/cb_{left,right}_hand_control_cmd` 为 JointState，20 个 0–255 电机值；状态 `/cb_{side}_hand_state`。G20 映射继续用逐值移植的 `g20_mapping.py`。
- LinkerTA 的 `/{side}_arm_joint_control` 是度；`/rokae/{side}/joint_state.position` 是 rad，另有 ee_pose。状态不施加指令偏置。
- 快照的 map_left 加 `[+90,+90,-90]°`，map_right 加 `[-90,+90,+90]°`；之后依次做绝对限位和 startup 附近限幅。默认 margin=3°、max_delta=60°、startup limit 开启。移植保留顺序，当前仿真 startup reference 明确采用场景 home_q，而不是查询真实臂。
- 8 月 action 为左臂 7、右臂 7、左手 20、右手 20；臂为 action_joint_target_final rad，手为电机值。最终目标回放不重复加 90°。8 月样本声明 1147 帧、30 Hz，约 38.23 s；显式循环用于长时测试，不宣称有同等时长的独立原始数据。
- 仅仿真节点清单为手套、重定向、LinkerTA 输入；不启动手 SDK、珞石从臂或会给臂上电的状态节点。原校准录制脚本不能作仅仿真启动器。站上实际连接、ROS 查询和硬件测试均未执行。
- UDP 直达/NAT 关系沿用用户核实事实，本轮未复测；地址、用户名和绝对站点路径只留私有配置及计算日志。

更完整的源快照定位及第一次预检见 [PRECHECK.md](PRECHECK.md)。私有原始源保留在忽略目录，未将含站点地址的原始源码复制进公开文件。

## 设计依据与证据限度

MuJoCo 原生位置执行器、mimic equality 和碰撞掩码参考[XML 文档](https://mujoco.readthedocs.io/en/stable/XMLreference.html)和[建模文档](https://mujoco.readthedocs.io/en/stable/modeling.html)。新采集驱动沿用既有 SAPIEN 占位值：手 240/8/60、臂 20000/2000/500，armature 分别 1e-4/1e-2；未经硬件辨识。MuJoCo 复用既有固定任务的惯量合法化函数，只对违反惯量三角不等式的源张量投影，派生目录记录前后值，不修改源 URDF。SAPIEN 软驱动 mimic 与重力/科氏补偿、MuJoCo 原生等式与重力补偿不同，不能预先当成相同动力学。物理时间采用累计网格，避免每帧独立 round 漂移。

实际快照 `info.json` 是 LeRobot **v3.0**。选择 [LeRobot 0.4.0 固定源码](https://github.com/huggingface/lerobot/blob/v0.4.0/src/lerobot/datasets/lerobot_dataset.py)，其 CODEBASE_VERSION 为 v3.0；[包配置](https://github.com/huggingface/lerobot/blob/v0.4.0/pyproject.toml)支持 Python≥3.10。包版本与格式版本不能混淆。导出直接写 Parquet、tasks、episodes、stats/info 和可选对齐视频；默认状态 56 rad、动作 54 混合单位、信号/mask 各 32、位姿 84。均匀 LeRobot 时间戳与实际引擎时间分字段保存。

overlay 复制自用户手柄仓库修订 `8d916d8e7dd039e3a0d73168990eca46ca8b4694`，许可证为 MIT 与原渲染器 The Unlicense；保留两个许可和 upstream.json，原来源 sevaht/gamepad-overlay 修订 `31236cd6a029828c8b01966ddc1a92c31e5cd852`。未修改复制渲染器或阈值，不称用户仓库为官方项目。画面只接收物理完成状态，独立进程渲染，采用支持 CPU 的 MJPEG；原 NVENC 路径不能在无空闲 GPU 时作为已通过证据。

## 原因分析与验证边界

审阅者确认 8 月桌面/手柄布置与当前不同；本轮记录显示右掌根可以低于当前台面，且存在真实碰撞，因此按裁决 2 分开评价。两后端接触下不同还可能涉及求解器、SDF 碰撞、mimic 与补偿方式，不能仅凭误差认定唯一原因。

确认 MuJoCo 完整接触回放比自由空间短测慢。关闭画面并限制 BLAS 线程的组合干预仍慢，不能单独归因线程。接触布尔扫描短路保持所有物理步和参数。唯一 8-worker 对照在相同前 0.5 s 得到约 1.647× 速度比，关节及位姿逐值相同；完整描述性回放显式用 `--mujoco-workers 8`，L1/L2 保持单 worker。未改 SDF/迭代/步长或控制器参数，也不把短段速度外推为整段固定速度。

## 修复预算

共享 tip helper：1 次，改用 spec API 接受的 list。MuJoCo：第 1 次支持 30 Hz 累计时钟，第 2 次短路已置 true 的接触扫描，物理不变。SAPIEN 接触分类：1 次，正间隙候选排除并重录。导出：1 次，改掉 Python 3.10 不支持的 starred 索引写法，Parquet 和原生读回通过。EGL 诊断：1 次，显式平台选择后 llvmpipe 成功。连续 episode 备注：1 次，对 episode 元数据做独立复制，回归测试及两次连续 HTTP 录制复测通过。预览目标帧率：1 次，30 Hz 没有调度余量，改 60 Hz 并进行一次 90 s CPU 预览对照；默认数采/物理步进不变，对照显式选 60 Hz。

自有 episode 回放：1 次。用 `.033/.066/.100 s` 的量化后观测时间复现 30 Hz 下第三条指令晚一帧的问题，修为按 meta.fps 的控制网格调度，并容许浮点边界舍入；新增失败用例先复现再修复，最终 45 项通过。原 8 月 NPZ 时间戳分支未改变，L1/L2 数值证据不受此修复影响。

HTTP 端到端尝试共 3 次：第一次客户端启动过晚，服务已停止；第二次请求与录制成功，但验证发现备注串集；第三次修复后两个 complete episode 的备注分别正确。测试调用中出现过旧测试文件名和连接脚本名拼写错误，纠正工具调用，无产品代码修改。各步未超过 3 次修复，没有通过反复调参重跑门槛。
