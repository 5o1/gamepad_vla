## 审阅者裁决

**对K1-a的裁决：** [K1-a](../2026-10-22-gamepad-height/README.md)选定结果不予采纳。侧视图上臂约82–92°、前臂约−25°，手竖直且手指朝下，自上方抓住手柄；自然偏差4.8–5.9且随高度增大。审阅者指出原相对候选手型及腕部范围导致该问题，60 mm仅为全不合格时最小偏差的回退。K1-a正文作为负结果保留，其左右参考净空209.99/175.51 mm另作镜像复核。

**裁决1，预算澄清：** “64个CPU核，合计12小时”指同时最多64核、从任务最初开始计最多12小时墙钟，上界约768 CPU小时，不是12 CPU小时。已保留原起点，检查`nvidia-smi`、`uptime`及`nproc`后准备提高并行度。节点112核；本任务仍只用CPU，没有占用GPU。新的扩展批次尚未启动即收到停止指令。停止时任务墙钟约1.80小时，最后存活采样累计CPU保守计数约6.70小时；已终止进程的GNU time可能漏未回收子进程，不能用较小的终止后汇总替代该累计采样。

**裁决2，停止任务：** 用户决定不再自动搜索摆放。摆放只要求“离桌面不远不近”和“尽量位于画面中间”，由审阅者另行确定；握持和操作待采集参考位姿后分析。停止全部K1-b作业，删除生成的v4.5，不提交Git。本报告保留中间证据，不继续选优或补跑验证。

## 停止前采用的方法与证据限制

搜索沿用壳底净空60–220 mm、倾角0–30°及yaw−90°；完整手/臂距桌面≥30 mm；自然臂姿沿K1-a裁决3作为硬条件，无不合格回退。背壳两指接触固定关节、数字30°/0.31行程、摇杆八方向0.8、扳机0.8、点误差0.25 mm及原生非目标碰撞口径未放宽；相机为真实网格投影40 px/0.30 m门槛。

使用多初值有界TRF最小二乘：自然臂姿采样、人类式握持种子、共同摆放外层优化及固定掌位操作手指IK。近似接触、可达和表面距离仅用于优化，不能算作通过。已执行阶段与修复次数见[fixes.md](fixes.md)。

原始资料及适配：借鉴[DexGraspNet原论文](https://arxiv.org/abs/2210.02697)的多初值接触/穿透能量思路，未引入其数据、模型或力闭合估计；[SciPy有界最小二乘文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)用于TRF参数及边界；[MuJoCo碰撞文档](https://mujoco.readthedocs.io/en/stable/computation/index.html#collision-detection)用于原生复核。静态筛查没有证明动力学稳定、全局最优或不可达。
