# 任务 AA：示范扩增框架与恒等回放验收

**已完成审阅者裁决 1：原位恒等对照、原生反馈源、正常接触口径、1 mm 指尖硬门，以及新位姿的真实物理通过输出。** 最终正式 CLI 试跑 3 个新位姿，**2 条保留、1 条拒绝**；两条通过轨迹各有 255 帧、8,500 个物理子步。当前仅验证固定手柄的左拇指 dpad_down 合成示范，不代表真实人类示范或全手握持能力。

[使用说明](../../usage/demogen.md)给出完整 CLI；[当前验收数字](reviewer-1.json)为审核后的机器无关摘要，[初版拒绝证据](validation.json)保留裁决前的对照。原始 episode、完整 manifest 和中间失败均留在采集台独立数据目录，不进入 Git。本任务未 commit、未安装依赖、未用 GPU、未在计算节点求解或发送硬件命令。

## 当前结果

源示范在原位用现有 SAPIEN collection 后端闭环生成：读取实际 dpad 信号，到约 0.34 即停止加深，最终峰值 0.3511；记录 3 次操作、411 帧、13.7 s 逻辑物理时间。接近和回程各 1.5 s，非操作指收拢，另一臂使用自然避让姿态。alpha 是手关节目标之间的插值参数，不是手柄行程。四路 applied targets 和实际信号完整保存，没有手工标签冒充物理测量。

## 恒等对照与拒绝原因

identity 命令在源 spec 和源手柄位姿回放原 applied arm/hand targets，不经过迁移、IK、片段拼接、变速或扰动。本任务合成源的目标四路均已知；没有指令时只能退回实测关节值，不能将其称为恢复了未知原始指令。

| 对照 | 帧 / 物理子步 | 原始最深接触 | 超界子步 | 信号不符子步 | 结论 |
|---|---|---:|---:|---:|---|
| 原纯运动学源，原位、统一 1 µm | 360 / 12,000 | 15.9877 mm，右拇指 distal—左拇指 metacarpals | 11,954 | 1,691 | 迁移之前就失败；3 个 up 事件均未触发 |
| 最终原生反馈源，原位、统一 1 µm | 411 / 13,700 | 26.4027 µm，dpad—左拇指 distal | 2,265 | 0 | 信号与双臂姿态正确，剩余失败仅为正常操作的数值负距离 |
| 同一反馈源，同位姿、校准正常操作口径 | 411 / 13,700 | 同上 | 0 | 0 | 通过，三次目标事件均触发 |

第一条直接排除了“必须是换位姿或拼接才导致失败”的解释。原左右静态候选各自验收，不能推定把它们同时放入动态场景仍无干涉；修正源同时采用另一臂避让和非操作指收拢，没有声称单独测出了两项修改各自的贡献。

另一个反馈较快的中间源虽然物理信号正确，却在回程中出现 applied hand target 与源实测手关节 FK 的约 2.6235 mm 差异，两个生成候选被新增指尖门拒绝。将源接近/回程由 0.4 s 延长至 1.5 s 后，该复现误差降至上述 0.68 mm 以内；这与动态跟踪滞后解释相符，不能将原差异算作 IK 重解误差。本任务保留这一拒绝统计，未提高 1 mm 上限。早于实测参考修正的 3 条中间输出已标记 discarded/superseded，不计入当前通过数。

## 正常接触口径及依据

采集代码中的 robot_contact 只是距离 ≤0 的接触 OR，不是穿透验收阈值。PhysX 的 contact offset 用于提前生成接触，rest offset 决定静态间距，负 separation 表示几何负距离；不能把 contact offset 或按钮机械行程直接当成允许的穿壳深度。依据为 [NVIDIA PhysX 接触说明](https://nvidia-omniverse.github.io/PhysX/physx/5.1.2/docs/AdvancedCollisionDetection.html)。

用同一机器人、姿态、驱动、原生 1 ms 步长和缓慢递增的下压目标，比较 full 与采集 gamepad-contact。只改变环境碰撞开关，手柄接触保持；两者得到相同的最低闭合附近结果：

| 手关节插值 alpha | 实际 down 信号 | full 原始负距离 | gamepad-contact 原始负距离 |
|---:|---:|---:|---:|
| 0.960 | 0.30895 | 22.7743 µm | 22.7743 µm |
| 0.961 | 0.32631 | 24.0771 µm | 24.0771 µm |
| 0.962 | 0.34103 | 25.7197 µm | 25.7197 µm |
| 0.963 | 0.35828 | 27.0440 µm | 27.0440 µm |

据此，在新位姿验收前固定 30 µm 的正常操作数值上限，留约 3 µm 数值余量。最终自动回归还用整个反馈轨迹作 full/gamepad-contact 成对比较，逐帧信号最大差为 0，两者最深该接触均为 26.4094 µm。这是当前固定仿真配置的经验校准，不是实物材料可穿透 30 µm 的声明。

该口径只适用于 SAPIEN 3.0.3、手柄包 0.4.1、左 thumb_distal—移动 dpad，且序列全为 dpad_down。配置的最大值在代码中封顶为 30 µm；默认仍是统一 1 µm。壳体、其他手指、手间、夹具、桌面、立柱仍执行 1 µm；其他控件和 MuJoCo 不套用此校准。raw_negative_contact_substeps 和原始最小距离始终记录；normal_control_contact_substeps 统计该校准接触对出现负距离的子步，其中仍可有超界子步，不能把这个计数当作全数获准。

因此本任务修正的是“正常操作接触”与“无关几何穿透”混在一起的口径，未把所有接触放宽到按钮行程，也未忽略 d050 的 315 µm 拒绝。

## 实现结构与研究适配

| 模块 | 职责与复用 |
|---|---|
| demogen/episode.py | 原 episode_schema 与 collection_integrity 严格读取 v4；左右流、实测 q、信号、时间、场景和固定手柄位姿 |
| demogen/segments.py | 数字滞回/去抖、摇杆方向/转圈/幅值、扳机行程、阶段和来源、截断/重叠、稳定中性握持候选 |
| demogen/kinematics.py | 原 SerialChain FK 和 spec SE(3)；自然轴线特征、NumPy 局部 IK、SLERP |
| demogen/generate.py | 跨 episode 单侧选段、原 applied targets/实测参考区分、握持拼接、seed 变化、五指 1 mm 硬门、恒等轨迹 |
| demogen/validate.py | 原 collection 后端；逐原生子步的接触、完整实际信号和双臂自然姿态；整数 tick 调度 |
| demogen/output.py、pipeline.py | 原 EpisodeWriter、严格读回、通过后晋升输出、所有 attempt 的 manifest |
| demogen/synthetic.py | 原静态标签负例和原生信号反馈源；只生成测试数据 |
| scripts/demogen.py、configs/demogen/ | synthetic / index / identity / generate 编排；普通变化、无扰动对照和校准物理配置 |

方法参考 [MimicGen 的源片段选择、变换与拼接](https://mimicgen.github.io/docs/modules/datagen.html)、[TaskSpec 的参考物体、边界、插值和噪声](https://mimicgen.github.io/docs/modules/task_spec.html)及 [DexMimicGen IV-A/IV-D 的分臂片段与手指目标回放](https://arxiv.org/html/2410.24185v1#S4)。本项目适配为固定手柄、单侧序列，另一侧保持并参与验证；没有另引仿真框架、训练、BC/DAgger 或双手同步控制。

自然姿态从原 k1_natural_reference 的轴线定义提炼到新 ArmGeometry，FK 仍调用既有 SerialChain。上臂 10–35°、肘在肩的世界 X 前方、前臂俯仰 −10–25°、朝向手柄网格中心的水平偏差 ≤30°。网格中心参考点由已有几何归档恢复；源静态左臂 26.3728446082° / 13.3378779746° / 9.5500843051° 与原候选一致。任务 Z 的受保护文件和目录本任务未编辑；以后可将原脚本切换调用通用模块。

指尖门使用源实测手关节生成参考，将有意的幅度/扰动变化加到该参考，再用解出的臂 q 与待执行手目标重新 FK 比较。这样不会用同一个目标 FK 与自己比较。source targets 已知时按原目标回放，不用受接触负载影响的实测 q 冒充原驱动目标。

长序列还发现原生后端对重复 1 ms 请求累加的控制时钟存在舍入风险。编排改为向整数 tick 的绝对时刻提交差分 dt，20,000 tick 回归验证每次恰好推进一个 tick；保持原有物理步长、驱动和后端代码。没有通过放宽完整性时钟门解决行数问题。

## 证据边界与真实示范后续

目前通过范围是：固定夹持手柄、左拇指 dpad_down、两个重复操作的合成数据，以及本次列出的位姿/仿真版本。非操作指收拢；不证明全手持续握持、力闭合、双手协同、实机成功或学习收益。验证保留后端既有自碰撞过滤，未建模的夹具细节及过滤的同侧自碰撞不在证据范围。

d050 的单个 315 µm 超界接触尚未进一步定位。若需要扩大该位姿覆盖，最小对照可保持源片段、spec、seed、驱动和阈值不变，只改变过渡时间，比较原生最深接触、发生时刻、信号和指尖误差；若静态保持仍重现，则不能归因于过渡。该额外对照本轮未执行，未把候选原因写成已确认结论。

真实示范到来后，先逐侧核对完整性、applied targets 与实测状态、稳定握持、每次按键边沿、摇杆方向和扳机行程。先执行原位恒等回放，再测空间迁移，最后逐项打开速度、幅度和扰动，分别报告 attempted / IK rejected / physics rejected / accepted。真实握持接触和其他控件必须各自校准，不能直接借用本次 down 操作的 30 µm 口径；需要真人数据的扩增通过样本才能评价真实数据收益。
