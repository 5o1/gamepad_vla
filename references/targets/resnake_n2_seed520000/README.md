# 实际游戏目标回放

`timeline.jsonl` 保存一段现有 N2 游戏策略生成的完整 `xinput-normalized-v1` 20 维报告：31×20 游戏、种子 520000、100 个逻辑 tick、10 Hz，共 10 秒。只出现四个方向键通道；没有将其他控件截断或改写成方向动作。

推理使用 `resnake_gym` 的已提交修订 `0659a21` 及官方环境、检查点和报告接口，确定性选择动作。检查点、源码模块和时间线哈希，以及游戏配置保存在 `provenance.json`。源模型曾训练 600,047,616 个 tick；该段结束时得分 6，游戏尚未终止。这是逻辑时间的输入记录，不是灵巧手已经完成游戏的证据。

游戏源码和模型仅用于生成本输入；控制回放只需要已归档的时间线。原始模型不随仓库分发，原模型训练也不属于本输入的独立复现范围。可用 `scripts/record_game_targets.py` 和兼容的上游检查点生成其他序列，输出均留在调用者指定目录。
