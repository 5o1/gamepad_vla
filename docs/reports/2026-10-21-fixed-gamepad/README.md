# 固定手柄：接触基线与残差控制

已实现 AR5-5_0.8R 固定姿态下的 G20 左拇指方向键任务。高度反馈抬起动作将三条相同评测序列的平均 F1 从 **0.691 提高到 0.806**，峰值单接触力从约 **30 N 降至 11 N**。残差学习尚未优于基础控制，不构成完整手柄操作或真机成功。

固定来源：手柄开发分支 `84f43e6`、同源编译 MuJoCo `3.16.0+concon.sdf3689.2`、本仓库公开 G20/0.8R 输入。来源、校验和运行方法见[资源清单](../../../references/fixed_gamepad_resources.json)与[任务指南](../../usage/fixed-gamepad.md)。

## 接触与训练对照

相同五状态目标生成器，每序列 500 个控制步，控制周期 20 ms；方向键始终从实际接触后的关节位移读出。本离线表保留无准备段的历史协议（`warmup_seconds=0`）；后面的闭环准备对照单独记录 0.5 秒准备。全部结果统一按上游试验闭合阈值 **0.3** 重算，未排除切换时段。下表三序列为种子 100/101/102；它们是评测序列种子，不能替代多个训练种子。

| 基础控制 / 残差范围 | 训练步数 | F1（100 / 101 / 102） | 平均 F1 | 最大单接触力 |
|---|---:|---|---:|---:|
| IK 直接切换 | 0 | 0.670 / 0.679 / 0.726 | 0.691 | 30.42 N |
| IK 直接切换 + PPO，0.15 rad | 4096 | 0.435 / 0.359 / 0.467 | 0.420 | 129.48 N |
| IK 直接切换 + PPO，0.03 rad | 4096 | 0.596 / 0.660 / 0.661 | 0.639 | 37.19 N |
| IK 高度反馈抬起 | 0 | 0.816 / 0.788 / 0.815 | 0.806 | 11.21 N |
| 高度反馈 + PPO，0.03 rad | 32768 | 0.697 / 0.720 / 0.647 | 0.688 | 67.47 N |

各行使用相同摆放、0.3 N·m 的试验关节力矩上限。抬起基线的中性准确率均为 1，三条序列没有未响应的按压事件，穿透约 0.22 mm；按压响应中位数约 120 ms。较小残差范围解释了部分短训退化，但仍没有超过 IK，两个短训模型均未采用。

32768 步、四环境 PPO 也未超过基础控制，且出现更高接触峰值；该最终模型未采用。权重、精确源码归档、逐步轨迹与日志保存在计算节点，完整计数和未完成项见 [summary.json](summary.json)。

## 诊断依据

- 原展示位置“下”方向的 IK 误差约 5.2 mm。手柄在桌面内平移 28 mm、22.67 mm 后，四方向误差降至数值量级；高度、朝向和机械臂姿态不变。该摆放只用于任务配置。
- 几何可达并不保证接触有效：60 N·m 原占位驱动上限下出现约 1 kN 的壳体接触。只降低力矩上限的种子 100 对照支持继续采用 0.3 N·m；该值仍未经硬件辨识。
- 每次从同一悬停位进入目标、每方向保持 1 秒时，后半段目标通道均值 0.988–0.998，其他方向为零；指尖误差 0.11–0.19 mm，最大拇指 mimic 误差 0.0044 rad。连续序列却出现持续误按，支持改善方向间运动路径。抬起对照证实了这一改动的效果。

## 验证范围

原始 G20 一个连杆的惯量超出物理三角边界约 0.21%；只在派生模型中投影到最近有效张量，保留质量、几何及修正记录。冻结机械臂后的手掌变换与原 URDF 前向运动学逐元素最大差 `9.90e-7`，未套用旧 0.7R 证书。

CPU 回归 **119 passed、1 skipped**；跳过项为未安装的可选 `resnake_gym` 集成。任务测试覆盖目标切换、抬起阶段仍按原始目标计分、漏按与延时以及惯量投影。多进程验证运行了真实 MuJoCo、回合重置、PPO 更新和模型保存，但短回合验证不作为任务表现证据。

当前尚未完成多训练种子的有效残差策略、可靠游戏闭环、ABXY、摇杆、扳机、双手协调、人类姿态先验或实机复现。后续工作必须分别验证，不将测试通过或图像显示当作操作成功。

## 实际游戏回放与闭环

已归档[真实 N2 目标](../../../references/targets/resnake_n2_seed520000/README.md)：种子 520000、31×20、100 个逻辑 tick、10 Hz，完整 20 维报告，原策略直接执行时得 6 分且尚未结束。抬起 IK 在该原时序上的回放 F1 为 0.710，仍有 3 次未响应按压。

闭环让游戏接收实际物理报告，并根据实际游戏状态重新决策。它没有未来游戏目标，不能与预知整个目标序列的离线任务混为一谈。下面均为同一游戏种子，最多请求 100 tick；报告一致率分母为实际完成 tick。

| 控制器 / 阻尼 | 准备段 | 完成 tick | 得分 | 一致报告 | 峰值单接触力 |
|---|---:|---:|---:|---:|---:|
| IK / 8 | 无 | 16 | 0 | 0/16 | 4.67 N |
| IK / 8 | 0.5 s | 49 | 1 | 33/49 | 12.18 N |
| IK / 4 | 0.5 s | 41 | 2 | 33/41 | 15.34 N |
| IK / 2 | 0.5 s | 34 | 1 | 28/34 | 12.48 N |
| 16k PPO / 8 | 0.5 s | 38 | 1 | 25/38 | 15.69 N |

这些闭环全部以撞墙结束，没有达到游戏操作目标。准备段本身均无接触，改善了首个指令的进入条件；继续降低阻尼并未消除多方向误触。16k 检查点离线种子 100 的 F1 为 0.837，虽略高于相应 IK 的 0.816，也没有改善闭环，不能据此采用。

新增因果训练协议不提供未来目标（`lookahead_steps=0`），使用 0.1–0.6 秒保持时间、0.5 秒准备及阻尼 4；其 IK 在种子 200/201/202 的 F1 为 0.814 / 0.817 / 0.846，平均 0.826。对应独立的 32768 步、四环境试验仍在运行。真实记录的保持时间最短 0.1 秒、中位数 0.2 秒，原训练 0.3–0.8 秒且预知未来，存在任务分布差异。新协议的结果须与其自身基线及留出种子 200/201/202 比较，尚无完成后的学习效果结论。

## 奖励一致性对照

原连续乘积奖励在“目标方向为 1、错误方向为 0.31”时仍给约 0.69 分，比完全松开高；后者虽漏按，但不会向游戏提交冲突方向。这个可执行反例证明了奖励与数字执行标准存在排序差异，尚不证明它解释全部训练退化。

新的 `fixed-dpad-causal-v2` 参考钢琴任务的键匹配与无误按结构，采用 `tolerance − wrong_press`；与上游不同，本项目对完整可用信号向量计算匹配，并奖励中性匹配。对照保持物理、初始化、种子、目标分布和网络不变，比较相同四轮 PPO 更新（8192 个训练样本）的策略。新的 8192 步试验正在运行；原因果乘积奖励模型继续按计划训练，所有结果均保留。
