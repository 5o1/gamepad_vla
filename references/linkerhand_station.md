# 工作台硬件与配置边界

当前物理工作台使用两只 AR5-5_0.8R 七轴机械臂、左右 G20 灵巧手，以及一台顶置 RealSense。左右安装位置不代表 L/R 产品型号。相机外参和台面尺寸见场景配置及标定归档；相机设备序列号、控制器地址、CAN 接口和站点目录放在本地站点配置中。

仿真采用两套 `AR5_5_08R_W4C4A6`，安装位姿及关节零位仍需独立实机核验。G20 的控制协议槽位与几何关节映射由 `workstation/g20_mapping.py` 定义，不可仅凭产品名称推断。

机械臂状态发布节点连接控制器时可能给机械臂上电，不能视为无副作用的查询。实机命令、SDK 和驱动启动需要单独的硬件执行授权。软件停止脚本不能切断电机电源。

完整资源盘点、控制器操作说明、现场照片和旧会话记录保留在不参与 Git、打包或普通同步的私有资料目录。
