# 审阅者裁决

日期：2026-10-22。以下按时间顺序记录，后项覆盖前项的对应条款。

1. **初始 K1-a**：固定根、正面朝上、yaw −90°；加入 K0 的 20×24 mm 中部支柱。左右手严格遵守既定分工，无名指和小指持续原生背壳接触。View、Menu、Xbox 不在范围内。相机以真实网格和标定内外参判断完整手柄、双手五指尖及掌根的画内范围，边缘至少 40 px，三者几何中心到光心至少 0.30 m；不判断遮挡。
2. **裁决 1**：以外壳最低点距桌面为高度，60–160 mm、10 mm 一档，160 mm 为稳定性硬上限，不扩展。所有计数的握持/操作姿态，完整手和臂网格距桌面至少 30 mm。每高度以光轴与 root 高度平面的交点为中心，world x/y 各 ±60 mm、步长 20 mm，共 49 个位置。先计算相对候选，世界摆放只重算环境/臂 IK/相机项。支柱全高使用细截面；加宽底座只提出设计范围，不进入场景。
3. **裁决 2**：增加依据 URDF 关节轴线的肩、肘、腕特征点、FK 参考高度与多初值 IK 的自然姿态偏好。覆盖档位优先，再作双臂自然姿态硬筛选，再选最低高度、画面中心和视野余量。最佳覆盖档位没有自然解时不放宽，选择最小自然偏差并明示。原“肘角90°、前臂水平”的数值定义被裁决 3 替换。
4. **裁决 3（最终姿态定义）**：上臂前倾目标 20°，10°–35°，且肘在肩的 +x 侧；前臂俯仰目标 +10°，−10°–+25°；前臂水平朝向手柄几何中心，偏差 ≤30°。肘角只报告，不作门槛。三项自然偏差分别按目标到对应边界的距离归一化，取最大值；后摆额外拒绝。腕部中立是软偏好，排序位于最低高度之后、画面中心之前。参考构型改为 20°/+10°/朝向中心，并计算 10°或35° × −10°或+25° 的四个容差角点。增加标注角度的侧视诊断图。

最终排序：完整覆盖双手掌位对数量（若全为零则用左右控件覆盖数之和） → 双臂自然姿态硬筛选（无解时最小偏差，明确不合格） → 最低合格高度 → 腕部偏差 → 手柄几何中心距相机主点的像素偏差 → 最小视野余量。

支柱净高与扫描净空不同：柱顶接 K0 背壳点；扫描高度以整个外壳最低点定义。夹紧、承载、打印材料、底座实物改造和硬件运行均没有在本次获得授权。
